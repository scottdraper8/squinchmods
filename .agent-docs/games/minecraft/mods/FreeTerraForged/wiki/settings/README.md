# Preset Editor Settings

Choose a settings screen reachable in the preset editor. Each guide explains its visible controls in
everyday language, based on how the current code uses them. Pages mark visible controls with no
effect.

- [Climate Settings](climate.md) (temperature, moisture, and biome region shapes).
- [Filter Settings](filter.md) (river erosion and terrain smoothing).
- [Island Settings](island.md) (offshore island groups and their coastlines).
- [Miscellaneous Settings](miscellaneous.md) (snow, stone layers, vegetation, and cave features).
- [River Settings](river.md) (river channels, wetlands, and boat flow).
- [Surface Settings](surface.md) (exposed rock, scree, and soil on slopes).
- [Terrain Settings](terrain.md) (landform regions, hills, plateaus, mountains, and volcanoes).
- [Underground Settings](underground.md) (cave shapes and underground biome regions).
- [World Settings](world.md) (continents, coasts, spawn, and vertical world levels).
