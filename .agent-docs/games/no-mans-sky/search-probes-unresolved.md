# Remote Arena size-class resolution

Research is paused at the user's request. Do not resume it or recreate its tests without
instruction.

Remote Arena searching exists in F7 and the backend command. Some eligible underwater creatures
still lack a definite remotely established adult size class. Different possible classes yield
different rank tuples and filter decisions. Searches continue and report these planets as
unresolved; that containment does not resolve the calculation gap.

The earlier `invalid generated fauna height` error is fixed. Discovery heights are signed metadata,
independent of placement. Wrong remote planet identity and crab component identity were corrected.
No incorrect returned Arena match has been demonstrated for the current installed build.

The scope expanded from a demonstrated depth/size dependency into probing things that _might_
influence placement or rounding. Those dependencies do not prove every building or game subsystem
changes Arena rank. Supporting prototypes did not complete ordinary-search integration.

Completion means resolving actual remaining class-dependent decisions and integrating the answer
into normal searches. Containing an error, hypothetical rolls, isolated helper comparisons or
repeating the existing shallow/deep observation do not complete that work.
