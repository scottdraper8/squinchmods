# Miscellaneous Settings

This page gathers controls for extra surface details, stone layers, cave features, and a few biome
options. Controls that currently have no effect are marked below.

## Snow and terrain materials

| Screenshot | Value                         | Description                                                                                                                                         |
| ---------- | ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
|            | **Natural Snow Decorator**    | Keeps snow off steep or rocky places where it is unlikely to settle.                                                                                |
|            | **Smooth Layer Decorator**    | Adjusts snow layer depth to follow the terrain more closely. It can be used on its own or with Natural Snow Decorator.                              |
|            | **Strata Decorator**          | Adds broad layers of soil, sand, gravel-like material, clay, and varied rocks beneath the surface.                                                  |
|            | **Strata Region Size**        | Sets the size of the patches that shape those layers. Larger values make the patterns broader. It only changes terrain when Strata Decorator is on. |
|            | **Ore Compatible Stone Only** | Intended to restrict rock choices to stone that supports ore. **This control currently has no effect.**                                             |
|            | **Plain Stone Erosion**       | Intended to use plain stone for eroded exposed rock. **This control currently has no effect on rock selection.**                                    |

## Plants and cave features

| Screenshot | Value                     | Description                                                                                                                                                     |
| ---------- | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|            | **Custom Biome Features** | Uses FreeTerraForged's versions of some vanilla plants and trees in place of the usual features. This changes the set of vegetation placed in supported biomes. |
|            | **Vanilla Springs**       | Controls whether Minecraft's underground water springs appear in the FreeTerraForged Overworld.                                                                 |
|            | **Vanilla Lava Springs**  | Controls whether Minecraft's small underground lava springs appear in the FreeTerraForged Overworld.                                                            |
|            | **Vanilla Lava Lakes**    | Controls whether Minecraft's underground lava pools appear in the FreeTerraForged Overworld.                                                                    |

## Biome choices

| Screenshot | Value                    | Description                                                                                                                                                                                  |
| ---------- | ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|            | **Mountain Biome Usage** | Intended to set how often mountain terrain receives a mountain biome, which can help other mods that check for mountain biomes. **This control currently has no effect on biome selection.** |
|            | **Volcano Biome Usage**  | Intended to set how often volcanic terrain receives a volcano biome, which can help other mods that check for volcano biomes. **This control currently has no effect on biome selection.**   |

Newly generated chunks use these settings.
