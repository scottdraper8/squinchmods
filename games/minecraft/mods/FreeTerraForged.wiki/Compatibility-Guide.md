# Compatibility Guide

A mod not being mentioned here does not mean it is not compatible; it means we haven't documented
its compatibility.

Broadly, FTF is compatible with anything that doesn't significantly alter or try to outright control
terrain generation. Specific advice around mod compatibility is captured below in an attempt to
concretely capture hard won tribal knowledge from the terrain generation community about what does
and doesn't play nicely and why.

This is not intended to be an exhaustive list but rather a starting point guide for common mods and
any issues / compatibility workarounds that users should be aware of.

## Performance mods

| Mod             | Link                                                  | Compatible |      Recommended      | Notes                                                                                                                                                                                                       |
| :-------------- | :---------------------------------------------------- | :--------: | :-------------------: | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **C2ME**        | [GitHub](https://github.com/RelativityMC/C2ME-fabric) |    Yes     | Strong recommendation | **If you install no other optimization mod, this should be the one you choose.**<br>Makes the single biggest difference to chunk generation speeds by preventing multithreading issues in world generation. |
| **FastNoise**   | [Codeberg](https://codeberg.org/ZenXArch/FastNoise)   |    Yes     |         Avoid         | Causes network protocol error on complex mod stacks.<br>Has negligible effect on modern generation stacks.                                                                                                  |
| **Noisium**     | [GitHub](https://github.com/Steveplays28/noisium)     |     No     |         Avoid         | Deprecated. Features are covered by larger optimization suites. Causes visible blocky grid artifacts during world generation                                                                                |
| **ScalableLux** | [GitHub](https://github.com/RelativityMC/ScalableLux) |    Yes     |      Recommended      | Lightmap updates on large vertical height worlds can get expensive. This optimizes those lighting engine calculations.                                                                                      |
