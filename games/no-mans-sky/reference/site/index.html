Scope

The item and technology glossary combines the current product, substance, technology, procedural technology and procedural product tables with all installed English localisation banks. The icon inventory includes every DDS whose archive path contains an icon or icons directory, plus UI DDS files with icon in the path outside those directories. The colour page is an isolated LUT comparison; it does not simulate lighting, exposure, fog, storms or HDR output.
